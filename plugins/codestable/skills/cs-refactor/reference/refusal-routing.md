# 重构适用性与调整路径

只有遇到对应疑问时读取。重构保留外部可观察行为；以下判断用于定位正确目标和证据，不是固定拒绝清单。

| 观察 | 处理 |
|---|---|
| 新能力或修正错误行为 | 行为变更交 feature / issue；已授权的独立重构可继续 |
| 缺少行为等价证据 | 自主补相称刻画测试、类型/调用验证或运行观察；无法取得关键证据时说明限制 |
| 跨模块职责问题 | 检查现有边界与授权；实质架构取舍才请 owner 决定，不把提案写成现状 architecture |
| 格式或个人口味 | 不包装成重构收益；已有规则可用 formatter，避免顺手全项目清理 |
| 生成产物或第三方代码 | 查生成源、扩展点或项目维护补丁方式及适用许可；许可证头本身不表示禁止修改 |
| 范围较大 | 按依赖和回滚边界分批，不用 15 文件/3000 行等固定上限要求用户缩范围 |
| 没有值得改的问题 | 如实报告零项；少量有效改动可走 cs-refactor-ff，不凑数量 |

需要 owner 判断时报告证据、可选动作和影响，其余范围内定位、准备和验证继续完成。不因为一个信号重复运行整份清单。
